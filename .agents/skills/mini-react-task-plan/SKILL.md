# Mini React 작업 계획

1. 이슈키나 요청에서 대상 동작을 찾고 [요구사항](../../../docs/requirements.md)의 관련 ID만 확인한다. 이슈 본문을 읽을 수 없으면 제공된 설명을 기준으로 삼고 확인하지 못한 점을 표시한다.
2. [아키텍처](../../../docs/architecture.md)의 관련 모듈과 실제 소스·테스트를 대조한다. 이미 합의한 계약, 제안 상태인 설계, 구현 전 결정이 필요한 항목을 구분한다.
3. 이번 변경의 범위와 유지할 계약을 적는다. 합격 기준마다 실제 테스트 명령이나 브라우저에서 조작할 단계와 기대 결과를 연결한다. 아직 없는 테스트 명령은 계획으로 표시한다.
4. **요구사항 ID와 근거 / 작업 범위 / 합격 기준과 검증 / 남은 결정**을 반환한다. 스킬의 산출물은 검토 가능한 작업 계획이다. Git·Jira 쓰기와 구현은 별도 작업 요청의 범위에서 처리한다.
