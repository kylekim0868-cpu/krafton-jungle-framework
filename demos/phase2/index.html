컴포넌트와 Hooks 실험실

입력과 클릭으로 루트 상태를 바꾸고, 기존 Diff·Patch로 화면을 갱신합니다.
이름만 바꿀 때와 숫자를 바꿀 때 렌더·Memo·DOM 관측 결과를 비교해 보세요.

이름과 숫자는 useState, 두 배 값은 useMemo, 문서 제목과 단축키는 useEffect로 관리합니다.

컴포넌트 영역

Hook 상태는 루트에 저장하며, 자식은 props로 화면을 만듭니다.

렌더·Memo·DOM 관찰

함수 실행, 계산 재사용, 성공한 반영과 DOM 관측 기록을 구분합니다.

아직 반영하지 않았습니다.

DOM 관측은 MutationRecord 수입니다. 이벤트 등록·현재 입력값 대입·레이아웃·페인트 횟수는 포함하지 않습니다. 적용 시간은 Diff·Patch 준비와 화면 그리기를 제외합니다.
