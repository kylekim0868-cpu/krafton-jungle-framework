루트 컴포넌트 실험실

루트 함수가 반환한 Virtual DOM으로 컴포넌트 영역을 만듭니다.
숫자를 바꾸며 기존 Diff·Patch로 화면이 갱신되는 흐름을 확인해 보세요.

버튼을 누르면 새로운 숫자를 props로 전달해 루트 함수를 다시 실행합니다.

컴포넌트 영역

mount로 처음 표시하고, update로 변경된 부분을 반영합니다.

렌더링 흐름

P2-01에서 사용하는 루트 함수와 공통 렌더링 엔진입니다.

오늘의 작은 실험

함수에서 화면까지

처음에는 mount()가 루트 함수의 VNode를 실제 DOM으로 만듭니다.

  • 새로운 props로 루트 함수 다시 실행하기
  • 이전 VNode와 새로운 VNode 비교하기
  • 기존 DOM의 변경된 부분만 반영하기

숫자를 바꿔도 컴포넌트의 제목과 설명 문단은 같은 DOM으로 유지됩니다.
